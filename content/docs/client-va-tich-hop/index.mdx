## Phạm vi dự kiến

Kết nối API với nhiều loại client, xử lý transport và mở rộng hệ thống bằng upload, persisted query hoặc federation.

## Các bài trong nhóm

- [GraphiQL, curl và Postman](/docs/client-va-tich-hop/cong-cu-goi-api) — Chọn công cụ gọi API phù hợp cho khám phá schema, debug và kiểm thử tự động.
- [Spring `WebClient`](/docs/client-va-tich-hop/spring-webclient) — Gọi một GraphQL service khác từ Spring Boot bằng WebClient và xử lý response/error.
- [Java GraphQL client](/docs/client-va-tich-hop/java-graphql-client) — So sánh các cách tạo Java client và quản lý query, variables, typing trong code.
- [Apollo/urql ở frontend](/docs/client-va-tich-hop/apollo-urql-frontend) — Kết nối frontend với Spring Boot GraphQL bằng cache, loading state và error policy.
- [File upload](/docs/client-va-tich-hop/file-upload) — Thiết kế upload file qua GraphQL và các giới hạn về multipart, storage, bảo mật.
- [Persisted query](/docs/client-va-tich-hop/persisted-query) — Giảm payload và kiểm soát operation được phép chạy bằng persisted query.
- [Federation và schema stitching](/docs/client-va-tich-hop/federation-va-schema-stitching) — Phân biệt federation với stitching khi hợp nhất nhiều GraphQL service.
