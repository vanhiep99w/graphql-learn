## Phạm vi dự kiến

Đi từ project Spring Boot trống đến một endpoint GraphQL có schema, query mẫu và quy trình kiểm thử local.

## Các bài trong nhóm

- [Khởi tạo project Spring Boot](/docs/bat-dau/khoi-tao-spring-boot) — Tạo project nền với Spring Boot và các lựa chọn cần thiết cho một ứng dụng GraphQL.
- [Thêm dependency và cấu hình](/docs/bat-dau/them-dependency-va-cau-hinh) — Cấu hình Spring for GraphQL, endpoint HTTP, schema locations và môi trường local.
- [Tạo schema đầu tiên](/docs/bat-dau/tao-schema-dau-tien) — Định nghĩa type, query và dữ liệu mẫu bằng GraphQL SDL trong project Spring Boot.
- [Viết query đầu tiên](/docs/bat-dau/viet-query-dau-tien) — Kết nối query với resolver và đọc kết quả từ endpoint GraphQL của ứng dụng.
- [GraphiQL và công cụ khám phá API](/docs/bat-dau/graphiql-va-kham-pha-api) — Dùng GraphiQL để đọc schema, soạn query, truyền variables và xem execution result.
- [Kiểm thử request bằng curl/Postman](/docs/bat-dau/kiem-thu-request-curl-postman) — Gửi GraphQL request qua curl và Postman để tạo quy trình kiểm thử lặp lại được.
