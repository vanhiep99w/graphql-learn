## Phạm vi dự kiến

Chuẩn hóa cấu hình, container, gateway, WebSocket, CI/CD và Kubernetes cho các môi trường triển khai khác nhau.

## Các bài trong nhóm

- [Profile và external configuration](/docs/trien-khai/profile-va-external-config) — Tách cấu hình GraphQL, database và security theo profile mà không hard-code secret.
- [Docker image cho Spring Boot](/docs/trien-khai/docker-image-spring-boot) — Đóng gói ứng dụng thành image nhỏ, reproducible và phù hợp với runtime production.
- [Reverse proxy và gateway](/docs/trien-khai/reverse-proxy-va-gateway) — Đặt GraphQL sau reverse proxy hoặc API gateway và xử lý header, timeout, routing.
- [Subscription qua WebSocket](/docs/trien-khai/subscription-websocket-deployment) — Cấu hình upgrade connection, sticky session và timeout khi deploy subscription.
- [CI/CD](/docs/trien-khai/ci-cd) — Xây pipeline kiểm thử schema, build image và triển khai ứng dụng an toàn.
- [Kubernetes](/docs/trien-khai/kubernetes) — Chạy GraphQL Spring Boot trên Kubernetes với service, config, probe và resource limit.
