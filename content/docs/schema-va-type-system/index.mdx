## Phạm vi dự kiến

Thiết kế schema có thể đọc được, kiểm soát nullability và tổ chức type để Spring for GraphQL dễ mở rộng.

## Các bài trong nhóm

- [SDL và nguyên tắc thiết kế schema](/docs/schema-va-type-system/sdl-va-thiet-ke-schema) — Giới thiệu GraphQL SDL và các nguyên tắc đặt tên, ownership, boundary cho schema.
- [Scalar, object và field](/docs/schema-va-type-system/scalar-object-field) — Phân biệt scalar với object type và cách field tạo nên contract của API.
- [Enum, input object và arguments](/docs/schema-va-type-system/enum-input-arguments) — Mô hình hóa lựa chọn hữu hạn, input gửi vào mutation/query và arguments có kiểu rõ ràng.
- [List và nullable](/docs/schema-va-type-system/list-va-nullable) — Đọc ký hiệu list/non-null và chọn nullability phù hợp cho dữ liệu trả về.
- [Interface và union](/docs/schema-va-type-system/interface-va-union) — Dùng interface và union để biểu diễn nhiều loại kết quả trong cùng một field.
- [Tách schema theo module](/docs/schema-va-type-system/tach-schema-theo-module) — Tổ chức nhiều file SDL theo domain và để Spring for GraphQL hợp nhất thành một schema.
