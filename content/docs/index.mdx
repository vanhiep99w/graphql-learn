## Lộ trình học

- [Nền tảng](/docs/nen-tang) — Các khái niệm cốt lõi cần nắm trước khi xây dựng API GraphQL với Spring Boot.
- [Bắt đầu](/docs/bat-dau) — Các bước dựng project Spring Boot đầu tiên và gửi request GraphQL chạy được.
- [Schema và type system](/docs/schema-va-type-system) — Cách mô hình hóa API bằng GraphQL SDL và hệ thống type an toàn.
- [Query, mutation và subscription](/docs/query-mutation-subscription) — Các operation chính của GraphQL và kỹ thuật truy vấn dữ liệu thực tế.
- [Tích hợp Spring for GraphQL](/docs/tich-hop-spring-for-graphql) — Cách ánh xạ schema GraphQL vào controller, service và lifecycle của Spring Boot.
- [Truy cập dữ liệu và hiệu năng](/docs/truy-cap-du-lieu-va-hieu-nang) — Kết nối GraphQL resolver với data layer và kiểm soát chi phí truy vấn.
- [Client và tích hợp](/docs/client-va-tich-hop) — Các cách gọi API GraphQL Spring Boot từ công cụ, Java client và frontend.
- [Bảo mật và quan sát](/docs/bao-mat-va-quan-sat) — Bảo vệ GraphQL endpoint và tạo tín hiệu quan sát cho hệ thống Spring Boot.
- [Triển khai](/docs/trien-khai) — Đưa ứng dụng GraphQL Spring Boot từ local lên môi trường chạy thật.
- [Production](/docs/production) — Các quyết định vận hành, mở rộng và tiến hóa GraphQL API trong production.
- [Xử lý sự cố](/docs/xu-ly-su-co) — Playbook chẩn đoán các lỗi thường gặp khi phát triển và vận hành GraphQL Spring Boot.

## Mục tiêu

Sau khi hoàn thành lộ trình, người học có thể thiết kế schema, viết resolver bằng Spring for GraphQL, kết nối data layer, bảo vệ endpoint, kiểm thử và vận hành GraphQL API.
