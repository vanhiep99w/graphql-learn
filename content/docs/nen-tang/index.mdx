## Phạm vi dự kiến

Xây dựng mental model về GraphQL, cách một request được thực thi và vị trí của Spring Boot trong toàn bộ hệ thống.

## Các bài trong nhóm

- [GraphQL là gì?](/docs/nen-tang/graphql-la-gi) — Giải thích GraphQL, schema, operation và lý do GraphQL phù hợp với API có nhiều loại client.
- [GraphQL và REST](/docs/nen-tang/graphql-va-rest) — So sánh hai mô hình API qua cách định hình resource, fetching dữ liệu, lỗi và versioning.
- [Mô hình request/response](/docs/nen-tang/mo-hinh-request-response) — Mô tả cấu trúc request GraphQL, execution result, data, errors và extensions.
- [Kiến trúc GraphQL](/docs/nen-tang/kien-truc-graphql) — Phân biệt client, server, schema, resolver, data source và các lớp trong một hệ thống GraphQL.
- [Hệ sinh thái công cụ](/docs/nen-tang/he-sinh-thai-cong-cu) — Tổng quan Spring for GraphQL, GraphiQL, client library, gateway và công cụ kiểm thử.
