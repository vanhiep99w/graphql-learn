## Phạm vi dự kiến

Biến API chạy được thành API bền vững: có contract evolution, kiểm thử, hiệu năng, quan sát và khả năng scale.

## Các bài trong nhóm

- [Schema evolution và deprecation](/docs/production/schema-evolution-va-deprecation) — Thay đổi schema mà không phá client bằng deprecation, migration và contract governance.
- [Chiến lược kiểm thử](/docs/production/chien-luoc-kiem-thu) — Kết hợp unit, integration, schema, contract và end-to-end test cho GraphQL API.
- [Tuning hiệu năng](/docs/production/tuning-hieu-nang) — Đo và tối ưu thời gian parse, validate, resolve, database và serialize response.
- [Cache và persisted operation](/docs/production/cache-va-persisted-operation) — Thiết kế cache nhiều lớp và allowlist operation cho traffic production.
- [Monitoring và SLO](/docs/production/monitoring-va-slo) — Đặt chỉ số, dashboard và SLO phản ánh trải nghiệm thật của GraphQL client.
- [Scale ngang](/docs/production/scale-ngang) — Xử lý stateless HTTP, shared state, DataLoader và subscription khi chạy nhiều instance.
- [Compatibility và versioning](/docs/production/compatibility-va-versioning) — Quản lý tương thích ngược giữa schema, client, server và quy trình phát hành.
